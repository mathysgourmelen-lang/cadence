# Cadence

Cadence is a Mac app for scheduling Instagram Reels and YouTube Shorts. You pick videos from your computer, write the caption once, choose a time, and Cadence posts them through the official Instagram Graph API and YouTube Data API.

- Everything runs on your Mac. There is no Cadence server or account.
